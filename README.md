# ACDMeshImport
## Import and Export AC Odyssey Mesh in Blender.
Blender Script in Python to directly import AC Odyssey .Mesh files specifically of Cloth Meshes.
The script should be copied into Blenders Scripting Menu->New Text file and Run.
It opens a File open dialog to select the import file.
Use Blender Window->Toggle System COnsole to turn pn the console to see the log outputs.
First run will also add File->Import->AnvilSoft Mesh (.Mesh) and File_Export->AnvilSoft Mesh (.Mesh) menus.
If "Edit->Preferences->Add-Ons->Install from Disk" is used to install this file, then Blender will have these menus always.
